# GEBICHART — PAQUETE DE DISEÑO 3.0

Archivo entregable: `GEBICHART_DISEÑO.ZIP`.

Contiene el manual editorial aprobado (PDF), isotipo aprobado sin modificaciones de diseño, variaciones de tamaño PNG, favicons PNG/ICO, 26 iconos SVG, recursos decorativos SVG, tokens CSS, componentes CSS, muestra HTML y guía para Codex.

**Advertencia**: Los iconos son SVG reales. El logotipo aprobado de origen es un PNG (no vectorial); no se distribuye una reconstrucción SVG porque sería alterar el isotipo. El `favicon.svg` incrusta exactamente ese PNG dentro de un contenedor SVG, por lo que no es vectorial puro.

**Fuentes tipográficas**: No se incluyen archivos de fuentes. Consulte el manual del Ayuntamiento y gestione derechos/licencias antes de usar la fuente Burgos o Myriad Pro; quedan documentadas con alternativas configuradas en CSS.

**Colores**: referencias RGB municipales para negro, granate, verde, amarillo, dorado y gris, adaptadas a tokens web. El color del texto y el azul de foco son auxiliares de accesibilidad, no colores de marca.

La carpeta `static/gebichart/` se puede copiar directamente al sistema de archivos estáticos del proyecto Django. No contiene Python ni modifica la base MariaDB.
