# Fuentes y licencias

- Burgos Roman / Light: tipografía corporativa indicada en el manual municipal; comprobar licencia y autorización para implantación web antes de usar `@font-face`. No se incluyen archivos de fuente en este paquete.
- Myriad Pro: tipografía complementaria indicada en manual municipal; su redistribución puede requerir licencia. No incluida.
- Georgia / Segoe UI / Arial: fuentes de respaldo del sistema operativo del usuario.
- Source Sans 3: alternativa libre; obtener desde un distribuidor oficial y verificar licencia si se desea autoalojar.
- No se incluyen tipografías ni datos reales del Ayuntamiento.
